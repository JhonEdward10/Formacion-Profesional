Los comienzos fueron con MS-DOS

Ya casi no se utiliza MS-DOS, solo se utiliza el formato de GUI, y los mas utilizados de los sistemas operativos son apartir de Windows 7 hasta hoy dia Windows 11.

Para conectar el hardware con el software aplicativo se utiliza una capa de abstracion que esto permite la comunicación entre el hardware y el kernel.

El código que se ejecuta en el modo de núcleo tiene acceso ilimitado al hardware subyacente y es capaz de ejecutar cualquier instrucción de la CPU. Un error en el modo núcleo y puede parar la computadora. Todo el código que se ejecuta en el modo de núcleo usa el mismo espacio para la dirección postal. Si se produce un error con el controlador en el modo de núcleo y escribe en el espacio para la dirección postal incorrecto, el sistema operativo u otro controlador del modo de núcleo podrían verse afectados negativamente.

Hay diferentes sistemas de archivos de Windows entre ellos exFAT, Sistema de archivos jerárquicos (HFS), Sistema de archivos extendidos EXT, Sistemas de archivos de nuevas tecnologías (NTFS); NTFS es el sistema de archivos más utilizado en Windows por numerosas razones. NTFS admite archivos y particiones muy grandes y es muy compatible con otros sistemas operativos. Además, NTFS también es muy confiable y admite funciones de recuperación.

.En NTFS hay un sistema alternativo para guardar información llamada Flujo de datos alternativos (ADS),  son unos "huecos secretos" que tiene el sistema de archivos NTFS para guardar información adicional sin crear archivos separados.

.También por otro lado existen los procesos y subprocesos de las aplicaciones: Una aplicación de Windows se compone de procesos. Un proceso es cualquier programa que se esté ejecutando. Cada proceso en ejecución está compuesto de, al menos, un subproceso. Un subproceso es una parte del proceso que puede ejecutarse.
