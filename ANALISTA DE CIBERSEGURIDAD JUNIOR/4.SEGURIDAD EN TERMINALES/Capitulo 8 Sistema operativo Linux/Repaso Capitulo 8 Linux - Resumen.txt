RESUMEN CAPÍTULO 8 - SISTEMA OPERATIVO LINUX (Repaso)

=================================================================
1. EL SOC (Security Operations Center)
=================================================================
- Es una plataforma que monitorea, detecta y responde a amenazas de
  seguridad. Funciona como el "cuartel general" de seguridad de una empresa.
- Herramientas del SOC:
    · Software de captura de paquetes (Wireshark) - analiza el tráfico de red
    · Herramientas de análisis de malware
    · Sistema de detección de intrusiones (IDS)
    · Firewalls
    · Administradores de registros
    · Gestión de información y eventos de seguridad (SIEM)
    · Sistema de tiquetes
- Kali Linux = distro con muchas herramientas para auditoría y pentesting.

3. PUERTOS EN LINUX (importante memorizar)
=================================================================
Rangos de puertos:
    · Well-Known Ports (0 - 1023)
    · Registered Ports (1024 - 49,151)
    · Dynamic / Private Ports (49,152 - 65,535)

Puertos importantes:
    20 - FTP - Data (datos)
    21 - FTP - Control
    22 - SSH (Secure Shell)
    23 - Telnet
    25 - SMTP (correo)
    53 - DNS
    67 - DHCPv4 (cliente a servidor)
    68 - DHCPv4 (servidor a cliente)
    69 - TFTP
    80 - HTTP

6. ENLACES SIMBÓLICOS (SYMLINK) vs ENLACES DUROS (HARD LINK)
=================================================================
- Symlink (enlace simbólico): un archivo que apunta a otro archivo o carpeta.
  Es como un acceso directo de Windows.
    · Crear:  ln -s /ruta/original /ruta/acceso_directo
    · Si borras el ORIGINAL, el symlink queda ROTO (apunta a la nada).
- Hard link (enlace duro): otra referencia al mismo archivo real (mismos datos).
    · Si borras el ORIGINAL, el hard link SIGUE funcionando.
- REGLA CLAVE: el hard link SOBREVIVE, el symlink SE ROMPE.
- Identificar symlinks con: ls -l  (aparecen con flecha -> )
- En hacking: los atacantes usan symlinks para engañar sistemas y acceder
  a archivos protegidos.

7. LOGS (REGISTROS DEL SISTEMA) - /var/log/
=================================================================
- Los logs son archivos donde Linux registra todo lo que pasa.
  Principalmente viven en /var/log/.
- Ver todos los logs:  ls /var/log/
- Logs más importantes:
    · /var/log/syslog        -> eventos generales del sistema
    · /var/log/auth.log      -> intentos de login (CLAVE para seguridad)
    · /var/log/kern.log      -> eventos del kernel
    · /var/log/dmesg         -> mensajes de arranque y hardware
    · /var/log/dpkg.log      -> instalación de paquetes
    · /var/log/boot.log      -> mensajes de arranque
- Ver logs en tiempo real:        sudo journalctl -f
- Ver logs de un servicio:        sudo journalctl -u nginx   (o -u ssh)
- Ver intentos de login fallidos (fuerza bruta):
    sudo grep "Failed password" /var/log/auth.log
    · Este comando muestra quién intentó entrar al sistema y falló.
    · Es clave para detectar ataques de fuerza bruta.
- Contar intentos fallidos:  grep "Failed password" /var/log/auth.log | wc -l

8. SISTEMAS DE ARCHIVOS
=================================================================
    Sistema   Uso                  Característica
    ext4      Linux moderno        Rápido, estable, journaling
    ext3      Linux antiguo        Con journaling
    ext2      Muy antiguo          Sin journaling
    NTFS      Windows              De Microsoft
    FAT32     USB antiguos         Máximo 4GB por archivo
    exFAT     USB modernos         Sin límite de tamaño
    NFS       Red                  Compartir por red

- Ver sistemas de archivos:  df -T
- Ver cómo están montados:   mount | column -t
- Journaling: es como un "cuaderno" donde el sistema anota lo que va a
  hacer antes de hacerlo. Si se corta la luz, puede recuperar los datos.
  Por eso Linux es más resistente a fallos que sistemas antiguos.

9. DIRECTORIOS MÁS USADOS EN LINUX
=================================================================
    /        Raíz, directorio principal (todo cuelga de aquí)
    /home    Carpetas personales de los usuarios
    /etc     Archivos de configuración del sistema
    /var     Datos variables, logs (/var/log), cachés
    /bin     Comandos/ejecutables esenciales (ls, cat...)
    /sbin    Programas de administración del sistema
    /usr     Programas y aplicaciones instaladas
    /tmp     Archivos temporales
    /opt     Software opcional de terceros
    /root    Carpeta personal del superusuario root (no tiene /home)
    /mnt y /media   Puntos de montaje de discos/USB
    /proc    Información del sistema en tiempo real (procesos)
    /dev     Dispositivos (discos, USBs)
