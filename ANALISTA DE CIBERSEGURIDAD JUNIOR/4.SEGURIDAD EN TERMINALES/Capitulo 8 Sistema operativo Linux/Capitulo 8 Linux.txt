Capitulo 8 Linux

EL SOC es una plataforma que monitorea y es como el cuartel general de una empresa ya que detecta y responde a amenazas de seguridad.

algunas herramientas de SOC son:
. software de captura de paquetes: WIreshark para analizar tipo de trafico en una red.
. Herramientas de analisis de malware
. Sistema de detecion de intrusiones (IDS)
. Firewalls
. Administradores de registros
. Administracion de informacion y eventos de seguridad.
. Sistema de tiquetes

Entre estas herramientas de pentesting se encuentra Kali linux, una distro con muchas herramientas para auditoria y pentensting

En Linux, los emuladores de terminal comunes son Terminator, eterm, xterm, konsole y gnome-terminal.

Puertos como se utilizan en linux
·  Well-Known Ports (0-1023) 

·  Registered Ports (1024 - 49,151)

·  Dynamic / Private Ports (49,152 - 65,535)

20 - File Transfer Protocol - Data (FTP-DATA)

21 - File Transfer Protocol - Control (FTP)

22 - Secure Shell (SSH)

23 - Telnet (TELNET)

25 - Simple Mail Transfer Protocol (SMTP)

53 - Domain Name System (DNS)

67 - Protocolo de configuración dinámica de host de cliente a servidor v4 (DHCPv4)

68 - Server to client Dynamic Host Configuration Protocol v4 (DHCPv4)

69 - Trivial File Transfer Protocol (TFTP)

80 - Hypertext Transfer Protocol (HTTP)
