Comandos de linux
Este es un espacio personal para hacer y escribir, ademas de aprender todos los comandos de Linux posible ademas de aprender lo necesario para hacer hacking.

nvidia-smi -> Para saber que comando se encuentra el driver NVIDIA.

ps -> Muestra los procesos que están corriendo en ese momento. Como una foto instantánea de lo que se ejecuta.
top -> Muestra los procesos en tiempo real actualizándose constantemente, con uso de CPU y memoria. Como un monitor en vivo.
kill -> Termina un proceso usando su PID (número de identificación). Para cerrar programas colgados.
